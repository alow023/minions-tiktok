# evaluator/local_evaluator.py is Python standard library only.

# starter/agent.py is standard library only EXCEPT for the semantic
# retrieval route (starter/semantic.py), which needs scikit-learn. That
# route is on by default and contributes the reported technical score of
# 0.897458. If scikit-learn is absent the agent catches the ImportError and
# degrades to the pure-standard-library lexical pipeline, which scores
# 0.896548 -- so the submission runs, and reproduces a documented score,
# either way. No network access and no pretrained weights are used in
# either case: the semantic space is factorised from catalog.jsonl itself
# at index-build time with a fixed random_state.
